# УрокоТека

Локальная веб-страница для поиска и скачивания записей уроков с платформы
[Контур.Толк](https://ktalk.ru). Вводишь имя записи или преподавателя — видишь
записи за последние 3 дня и скачиваешь их одним кликом.

## Возможности

- Поиск по названию записи **и** ФИО преподавателя за последние 3 дня.
- Таблица: название, преподаватель (с должностью), дата создания, длительность, размер.
- Скачивание видео (MP4) через локальный прокси — API-ключ не попадает в браузер.
- Конструктор имени файла: выпадающий список группы (AK / PG / NT) + ручные поля,
  имя собирается по шаблону `Группа XX <текст>  урок YY <текст>`.
- Ссылка «Открыть в Толке» на страницу записи.

## Требования

- Python 3 (стандартная библиотека, без сторонних пакетов).
- API-ключ Контур.Толк (кабинет → раздел API). Ключу нужны права на чтение
  записей домена.

## Установка и запуск

1. Задай ключ API одним из способов:
   - скопируй `config.example.py` в `config.py` и впиши свой ключ; **или**
   - задай переменную окружения `TALK_API_TOKEN`.
2. Запусти сервер:
   ```
   py server.py
   ```
3. Открой в браузере: <http://127.0.0.1:8765>

## Настройки

В начале `server.py`:

- `BASE_URL` — адрес пространства Толка (по умолчанию `https://matrius.ktalk.ru`).
- `DAYS_BACK` — за сколько дней показывать записи (по умолчанию 3).
- `PORT` — порт локального сервера (по умолчанию 8765).

## Безопасность

`config.py` с ключом исключён из git (`.gitignore`) и в репозиторий не попадает.
