# УрокоТека — история разработки

Хронология: что просил заказчик и что сделано. Актуальный обзор — в
[CONTEXT.md](CONTEXT.md). Даты — по ходу работы (июнь–июль 2026).

## 1. Разведка API и первая версия
- Задача: страница для поиска и скачивания уроков с Толка за 3 дня, по имени
  записи или преподавателю; видеть дату/время; минимальный интерфейс, быстро.
- Дан ключ API. Официальная дока закрыта для ботов → API разобран зондами.
- Найдено: `X-Auth-Token`, база `matrius.ktalk.ru`. Ключ сперва давал 403 на
  записях (не хватало прав) → заказчик включил права в кабинете.
- Ключевое открытие: `GET /api/domain/recordings` отдаёт весь домен;
  `/api/recordings/{key}/file` — сам MP4. Эндпоинты найдены в JS-бандле кабинета.
- Сделан `server.py` (Python stdlib): поиск за 3 дня + скачивание через прокси.
  Порт 8000 занят Windows → перешли на 8765.

## 2. Ссылка на запись

## 3. Имя сохраняемого файла
- Сначала — свободное поле для имени в каждой строке.
- Затем время: «первый комментарий» оказался недоступен (403 на чат,
  commentsCount обычно 0). Показали расчётное начало (`createdDate − длительность`)
  и `createdDate`; позже столбец «Начало (расч.)» убрали, оставили «Создано».
- Конструктор имени: выпадающий список группы **AK / PG / NT** + два свободных
  поля (цифры/точки/буквы), автоподстановка «урок XX». Формат:
  `Группа XX <поле1>  урок YY <поле2>` (ровно два пробела перед «урок»).
- Маппинг урока: **AK → урок AP**, PG → PG, NT → NT.
